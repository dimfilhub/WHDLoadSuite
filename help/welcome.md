# Welcome to WHDLoadSuite

WHDLoadSuite runs WHDLoad game archives (`.lha` files) in the Amiberry emulator, and can turn any game into a standalone program that you start with a double-click: a `.app` on macOS, an `.exe` on Windows, a program on Linux.

## How the pieces fit together

1. **Get the games.** Download them in the [Downloader tab](help:downloader), or copy your own `.lha` archives into the downloads folder.
2. **Find a game.** The [Browser tab](help:browser) lists every archive in the downloads folder and lets you search and filter by language, platform, memory and more.
3. **Try it.** Select a game and press **Launch in Amiberry** (Browser) or **Launch to test** (Builder). The [launch screen](help:launch-screen) shows the game's picture and lets you choose the joystick, window and screen look.
4. **Make a standalone program.** In the [Builder tab](help:builder), tick the games and press **Build App** (macOS) or **Build Exe** (Windows and Linux). See [Standalone executables](help:executables).
5. **Optional and experimental: an Amiga hard disk image.** The [HDCommander tab](help:hdcommander) copies games into an `.hdf` image that you can use in other emulators or on real hardware. It is still being tested, so work on a copy of your images.

## The main window

The window has four tabs and two menus.

- **Browser**: search and filter your archives, launch one, send some to the Builder.
- **Builder**: tick games, test-launch one, build standalone programs.
- **Downloader**: browse and download the Retroplay WHDLoad packs from the internet.
- **HDCommander (experimental)**: a two-pane file manager for Amiga hard disk images. Still being tested; see its page.
- **Settings menu**: **Browser…**, **Builder…** and **Amiberry…** open the [settings windows](help:settings).
- **Help menu**: this Help (press F1 for the page of the tab you are on) and **About WHDLoadSuite…**.

## Before your first game

You need two things that are not included, because they belong to other people:

- **The emulator**, Amiberry. See [The emulator (Amiberry)](help:emulator).
- **Kickstart ROMs**, the Amiga's system software. See [Kickstart ROMs](help:kickstarts).
