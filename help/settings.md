# Settings windows

The **Settings** menu opens three windows, one for each part of the app. Each shows its choices with a short note under each one.

- **Browser…** opens [Browser settings](help:settings-browser): the downloads folder.
- **Builder…** opens [Builder settings](help:settings-builder): the work folder, the prepared-games folder and the executables folder.
- **Amiberry…** opens [Amiberry settings](help:settings-amiberry): where Amiberry is, the launch choices, the launch screen, the ROMs and the game database.

## How they work

- **Changes apply at once** and are saved when you make them. There is no Save or OK button; **Close** (or Esc) just closes the window.
- If a window is already open, choosing it again brings it to the front instead of opening a second copy.
- The three windows can be open together; they open slightly offset so none hides another.
- The settings are kept in `.whdloadsuite.json` in the app's folder. See [Folder locations](help:locations).
