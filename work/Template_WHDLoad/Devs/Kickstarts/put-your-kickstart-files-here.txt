Put your Kickstart ROM images here (you must supply your own; they are copyrighted).

WHDLoad looks for ROMs in Devs/Kickstarts and identifies them by FILE NAME,
so each image must be a plain (decrypted) ROM dump renamed like this:

  kick<version><revision>.<model>

  File name          Kickstart                  Typical size
  -----------------  -------------------------  ------------
  kick33180.A500     1.2  (rev 33.180)          256 KB
  kick34005.A500     1.3  (rev 34.5)            256 KB
  kick37175.A500     2.04 (rev 37.175)          512 KB
  kick37350.A600     2.05 (rev 37.350)          512 KB
  kick40063.A600     3.1  (rev 40.63)           512 KB
  kick39106.A1200    3.0  (rev 39.106)          512 KB
  kick40068.A1200    3.1  (rev 40.68)           512 KB
  kick40068.A4000    3.1  (rev 40.68, A4000)    512 KB

Notes:
- Case matters on some systems: use the exact upper/lower case shown above.
- Which file a game needs is decided by the game's WHDLoad slave. If WHDLoad
  reports a missing Kickstart, add the file it names.
- ROMs from Cloanto's Amiga Forever are encrypted (they need a rom.key); decrypt
  them first or use unencrypted dumps.
- Reference: the "Kickstarts" section of the WHDLoad documentation.
